# PicoDesk host toolchain

Python side of PicoDesk: PyQt6 GUI, MATLAB extraction, RTE code generation, build
orchestration, and the XCP calibration master. See the repository root
[README](https://github.com/ernsoylu/picodesk) and `REQUIREMENTS.md` for the full picture.

Install for development (Python 3.9–3.11):

```
pip install -e "host[dev]"
```
